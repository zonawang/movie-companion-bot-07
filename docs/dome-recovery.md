# 大巨蛋秀泰的當日晚間場次修正

使用者輸入「大巨蛋秀泰今晚有哪些電影可以看？」時，正式主機讀取開眼回 HTTP 502；原有官方備援僅登錄文心、長春國賓與澎湖，大巨蛋尚未接入。秀泰官方公開場次頁可在本機讀取，但對現有 GCP 主機回 `403 / Blacklisted`。開眼公開行動版的 TLS 憑證已過期，不能當作可用備援，程式保留正常憑證驗證。

## 這次調整

1. 加入大巨蛋官方分館 `https://www.showtimes.com.tw/cinemas/91/`，核對大巨蛋名稱，不使用文心的資料或識別碼。
2. 開眼與官方頁均無法提供有效場次時，只為大巨蛋加入獨立公開整理者「場次通」的[分館頁](https://twshowtimes.com/cinemas/showtimes-dajudan/)。它是第三方時刻表，不是秀泰官方 API。來源介紹見[關於場次通](https://twshowtimes.com/about/)。
3. 同時核對 h1、MovieTheater JSON-LD 的名稱、固定分館 URL、地址、完整 ISO 日期、電影數量與每張卡片連結的日期。保留原片名、版本、實際時間與資料來源；格式變更或資料缺漏時明確失敗。
4. 「今晚」仍由 Google ADK 呼叫原有 `cinema_schedule`，由程式使用台灣日期及 18:00 篩選，不由模型猜片單。成功後沿用十張卡片、下一批導航與完整場次功能。
5. 文字、卡片、完整場次與「關於」均標示第三方來源、讀取時間與可能延遲；不將備援資料稱為官方資料。官網入口改為目前的分館頁，購票與臨時異動仍以官網為準。

僅匿名讀取場次通公開首頁，每次最多五秒、兩 MB，成功快取五分鐘、失敗冷卻三十秒、合併同時請求。不帶憑證、cookie 或登入 session、不使用代理，不代訂票。只使用頁面實際標示的日期；未解析未來日期頁，不把目前首頁當未來場次，也不在失敗時沿用過期快取。其他分館的來源選擇維持原邏輯。

## 驗證方式

- `test/dome-recovery.test.mjs`：分館與日期驗證、錯誤或不完整資料、502＋403 的實際失敗組合、18:00 篩選、版本保留、官方成功時不查第三方、跨日、快取過期、失敗冷卻、第三方標示與 Flex 完整場次。
- `npm run smoke:dome:recovery`：正式主機以全新 CinemaSource，直接將使用者原句送入真實 Gemini／Google ADK，確認 `cinema_schedule`、當日晚間真實場次、電影卡片、完整場次與下一批均通過 LINE `validate/reply`。只用記憶體票匣，不向 LINE 使用者發送訊息。
